# Core Ideas

- **Token:** a small piece of text represented by a number.
- **Embedding:** a learned vector for a token.
- **Parameter:** a number inside the model that training can change.
- **Loss:** how wrong the model's predictions are.
- **Gradient:** tells training how a parameter affects the loss.
- **Attention:** lets a token use useful earlier tokens.
- **Context window:** how many previous tokens the model can directly see.
- **Pretraining:** learning general language by predicting the next token.
- **Instruction tuning:** later teaching the model to answer users and follow instructions.
